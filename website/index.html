Integrate Fiber payments with one React component. Monetize AI agents with one CLI command.

fiber-pay is an AI-friendly toolchain for CKB Lightning on Fiber Network. Build production payment flows with a React-first SDK layer and run AI-agent-native command workflows with a CLI designed for automation.

Get started with the React SDK · Run the AI agent CLI flow · Browse examples

React-First SDK

Most teams integrate through @fiber-pay/react first, then drop down to lower-level SDK APIs only for advanced control. Start with component primitives, keep the browser-node lifecycle in hooks, and customize the panel UX as needed.

  • Quick entry: FiberPayQuickCard for invoice + payment flows.
  • Full panel: FiberNodeButton with tabs customization and i18n override.
  • Hooks: useFiberNode and useFiberPayment for controlled app state.
import { FiberPayQuickCard, FiberNodeButton, useFiberNode } from '@fiber-pay/react';

export function WalletPanel() {
  const fiber = useFiberNode({ network: 'testnet', walletId: 'demo-wallet' });

  return (
    <>
      <FiberNodeButton
        fiber={fiber}
        strategy="passkey"
        tabs={[{ id: 'workbench' }, { id: 'channels' }]}
        t={(key, fallback) => key === 'tabs.workbench' ? 'Workbench' : fallback}
      />
      <FiberPayQuickCard fiber={fiber} network="testnet" />
    </>
  );
}
Advanced: low-level SDK API (FiberRpcClient) 
import { FiberRpcClient } from '@fiber-pay/sdk';

const client = new FiberRpcClient({
  url: 'http://127.0.0.1:8227',
  biscuitToken: process.env.FIBER_RPC_BISCUIT_TOKEN,
});

const info = await client.nodeInfo();
console.log(info.pubkey);

AI Agent CLI

fiber-pay CLI is designed for AI agents and automation scripts, not just manual shell usage. Use it to bootstrap nodes, expose paid local agents via L402, and call remote paid agents from another profile.

  • One-command node startup and runtime inspection.
  • agent serve and agent call for paid AI workflows.
  • l402 proxy for monetizing existing HTTP APIs.
npm install -g @fiber-pay/cli

# 1) start local Fiber node
fiber-pay --profile demo node start --json

# 2) publish a paid AI agent service
fiber-pay --profile demo agent serve --agent codex --price 0.1

# 3) consume remote agent from another profile
fiber-pay --profile user agent call http://127.0.0.1:8402 --prompt "review this code"

# 4) monetize any HTTP API with L402
fiber-pay l402 proxy --target http://localhost:3000 --price 0.1
