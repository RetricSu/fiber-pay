CLI Engine

Use fiber-pay CLI as your operations control plane

The CLI is built for both manual workflows and scripted automation. It provides profile-aware configuration, node/channel/payment lifecycle control, runtime jobs, and machine-readable outputs for chaining tools.

  • Stable command groups: node, channel, payment, runtime, l402, agent
  • Consistent JSON output for parsers and bots
  • Useful for local smoke runs and CI pipelines

Quick CLI flow

npm install -g @fiber-pay/cli
fiber-pay --profile demo config init --network testnet
fiber-pay --profile demo node start --json
fiber-pay --profile demo node ready --json
fiber-pay --profile demo runtime status --json

SDK Stack

Build apps on top of typed Fiber primitives

@fiber-pay/sdk

Universal APIs and shared protocol building blocks.

@fiber-pay/sdk/node

Node-focused helpers, including L402 middleware and server tooling.

@fiber-pay/sdk/browser

Browser-ready clients and passkey-friendly runtime integration.

SDK example

import { FiberRpcClient } from '@fiber-pay/sdk';

const client = new FiberRpcClient({
  url: 'http://127.0.0.1:8227',
  biscuitToken: process.env.FIBER_RPC_BISCUIT_TOKEN,
});

const info = await client.nodeInfo();
console.log(info.pubkey);
