# Fiber SDK Examples Matrix

This folder contains the canonical demos grouped by SDK integration layer.

1. react-min-connect
- Layer: React integration (minimal)
- Focus: useFiberNode + ConnectButton only

2. react-fiber-node-button-lab
- Layer: React component
- Focus: FiberNodeButton default panel and custom extension points

3. browser-sdk-playground
- Layer: Browser SDK
- Focus: FiberBrowserNode + BrowserRpcClient + browser-only helpers

4. sdk-node-recipes
- Layer: Universal SDK (Node scripts)
- Focus: FiberRpcClient recipes for payment/channel/watch flows
